# 管理后端迁移记录（2026-11-25）

独立管理后端已上线，当前访问入口为 https://8.133.23.125。`lxladmin.cn` 指向同一站点，但公网 HTTP 返回阿里云 `Non-compliance ICP Filing` 页面，公网 HTTPS 连接被重置；服务器内部访问该域名正常。现阶段使用 IP 的有效 HTTPS 证书访问。

## 已完成

- 93 个活跃 API 路径及依赖进入本仓库 backend；原始提交和文件哈希见迁移 manifest。
- 管理服务使用独立密钥和 Cookie，通过专用 SSH 隧道访问原 PostgreSQL，数据库没有对公网开放，也没有执行生产迁表或 seed。
- Nginx 的 API 和媒体代理已切换到本机 3001。后端、隧道均启用 systemd 自动启动。
- 静态素材目录已同步；另外同步了不在 OSS 的 27 张头像和 9 张背景。视频检查确认共享 OSS 中已有对象。
- FFmpeg 沿用原容器的 5.1.9 运行包，传输 SHA256 校验及 H.264 编码测试通过。
- 常规赛事删除和竞猜权限在后端强制校验，支持钻石+段位并同步报名快照。管理商品列表不触发用户商城的数据初始化和修复。
- IP TLS 虚拟主机设为默认入口，确保不发送 SNI 的客户端也能收到 IP 证书。

## 验证与限制

前端 14 项单元测试、9 项竞猜/删除权限浏览器测试通过。后端 7 项单元测试和真实 PostgreSQL 临时集群集成测试通过；前后端生产构建通过。

生产验证完成共享 schema 字段兼容性检查、匿名拒绝，以及短期内部会话下的权限、用户、常规赛、战队赛、商品、赞助、音乐等读取；段位图标、历史头像和音频 Range 均成功。没有在生产执行审核、充值、删除或段位修改来做测试。生产未重置管理员密码；环境中的旧初始化密码不能作为当前账号密码使用，真实密码登录由隔离测试覆盖。切换后使用现有账号密码重新登录。

原用户站点 `/login` 返回 HTTP 200。原应用、数据库和旧后台继续运行。原有少量前端浏览器用例仍需更新旧标题及按钮选择器，未声称全套浏览器测试通过。
